# 개인정보와 저장

이 문서는 Mosaic 0.7.4의 실제 저장·통신 동작을 설명합니다. 문의: tensordev9@gmail.com (설정의 **문의하기**). 공개 운영자 표기는 아직 미정입니다. [English guide and privacy summary](quickstart.en.md)

## 기기에 저장되는 정보

사이트 권한(알림·위치·카메라·마이크 등)의 허용·거부는 해당 화면의 사이트별로 이번 앱 실행 중에만 기억합니다. 같은 요청으로 반복해서 묻지 않으며, 다른 화면·프로필·사이트에 허용을 공유하지 않습니다. 앱을 다시 시작하면 다시 물을 수 있습니다. 권한 선택은 파일이나 집계 서버에 저장하지 않습니다.

기본 위치는 `%APPDATA%\MosaicBrowser`입니다. 설치판과 압축판, 이전 Mosaic 버전이 이 위치를 공유합니다. 개발·검사에서는 `MOSAIC_USER_DATA`로 별도의 폴더를 지정할 수 있습니다.

| 정보 | 저장 위치/방식 | 포함될 수 있는 내용 |
| --- | --- | --- |
| 작업 공간 | `workspace.json`와 복구용 사본 | 화면 주소·제목, 프로필 표시 이름, 세트와 배치 |
| AI 대화 | `ai-chats.json`와 복구용 사본 | 사용자 요청, AI 응답, 작업 기록과 제공자 세션 정보 |
| 저장한 로그인 정보 | `credentials.bin` | 계정명과 비밀번호; Windows의 Electron 암호화 저장소 사용, 암호화 불가 시 평문 저장하지 않음 |
| 로그인 세션 | `sessions/`, Chromium의 `Partitions/` 및 사이트 저장소 | 쿠키, localStorage, IndexedDB 등; 별도 세션 스냅샷은 암호화되지만 모든 사이트 저장소가 동일하게 암호화되는 것은 아님 |
| 연결 Chrome | `chrome-profiles/` | Mosaic 화면별 Chrome 쿠키·사이트 저장소 |
| 로컬 AI 연결 | `agent-connection.json`, `ai-connections/`, `ai-workspaces/` | 로컬 연결용 토큰과 실행 상태; 공개하거나 지원 요청에 첨부하지 말 것 |
| 앱 설정·선택적 사용 횟수 | `app-settings.json` | 표시 언어, 첫 안내 표시 여부, 기록 동의, 날짜별 숫자 |
| 선택적 서버 집계 동의 | `usage-consent.json` | 별도 전송 동의, 무작위 설치 ID, 전송 대상 구분값과 마지막 전송 날짜 |

작업 공간과 AI 대화 파일은 평문 JSON입니다. 사용자 데이터 폴더 전체를 공개 저장소, 파일 공유 또는 오류 제보에 올리지 마세요. 같은 Windows 계정에 접근할 수 있는 사람이나 프로그램으로부터 모든 저장 내용을 분리해 주는 제품은 아닙니다.

## 선택적 사용 횟수

**이 기기에 사용 횟수 기록**은 기본적으로 꺼져 있습니다. 켜면 앱 실행과 AI 요청 시작·응답 종료·오류·중단 횟수를 날짜별로 최대 90일간 저장합니다. 날짜는 UTC 기준입니다. 각 날짜와 이벤트의 수치는 1,000,000에서 제한됩니다.

이 기기 내부 기록에는 URL, 페이지 제목·본문, 프롬프트·대화, 쿠키, 비밀번호, 계정 식별자를 넣지 않으며 서버에 업로드하지 않습니다. 기록을 끄면 기존 횟수도 지웁니다. **사용 횟수 지우기**는 기록을 켠 상태로 숫자만 초기화합니다.

AI의 **응답 종료** 횟수는 제공자의 실행이 끝났다는 뜻입니다. 실제 웹사이트에서 작업이 성공했는지 검증한 횟수나 제품 성공률로 해석할 수 없습니다.

## 별도 동의를 받는 사용자 수 집계

**사용자 수 집계에 참여**는 기본적으로 꺼져 있으며 기기 내부 기록과 독립적입니다. 기존 로컬 기록 동의를 서버 전송 동의로 처리하지 않습니다. 서버가 연결되지 않은 빌드에서는 옵션을 켤 수 없고 전송도 없습니다. 연결된 빌드는 설정에 PostHog 미국 또는 유럽연합 수신 지역을 표시합니다.

켜면 기기에 무작위 설치 UUID를 만들고 실행 중 하루에 한 번 활성 설치 이벤트를 보냅니다. 포함하는 값은 설치 ID, 전송 시각과 이벤트 구분값, 앱 버전, OS 종류·CPU 아키텍처, 동의 정책 버전입니다. 기기 일련번호나 계정에서 ID를 만들지 않습니다. 여러 데이터 폴더·재설치·동의 철회 후 재동의는 별개의 설치로 잡힐 수 있습니다.

URL·방문 기록·프롬프트·대화·계정·쿠키·비밀번호·파일 경로·스크린샷은 전송하지 않습니다. 자동 클릭 수집·세션 녹화·사람 프로필 생성·위치 분석을 사용하지 않으며 이벤트의 IP 값은 null로 지정합니다. 다만 PostHog와 통신 인프라는 IP 등 연결 정보를 볼 수 있으므로 완전한 익명이라고 주장하지 않습니다. [PostHog 수집 제어](https://posthog.com/docs/privacy/data-collection)를 참고하세요.

끄면 진행 중 요청에 취소를 보내고 새 전송을 중지하며 로컬 ID를 삭제합니다. 이미 서버가 받은 기록은 자동 삭제되지 않습니다. 서버 보관기간·접근 권한·수신 지역·삭제 문의처는 공개 전에 운영자가 확정해야 합니다. 현재 프로젝트 연결과 운영자 정보가 미정인 배포본은 공개 준비 완료 상태가 아닙니다.

전송 실패는 앱 사용을 막지 않으며 시간당 최대 한 번 재시도합니다. 과거 로컬 횟수나 오프라인 이력을 소급 전송하지 않습니다. 공개 지표는 **동의한 활성 설치 수**이며 전체 사용자 수나 실제 고유한 사람 수가 아닙니다. [집계 연결과 해석](analytics.md)을 참고하세요.

## 외부 통신

- 웹 화면은 사용자가 연 사이트와 통신합니다. 해당 사이트의 추적·저장 정책이 적용됩니다.
- AI를 실행하면 선택한 제공자에게 요청, 허용한 화면의 관찰 내용 및 요청한 스크린샷 등이 전달될 수 있습니다. 로컬 사용 횟수 기록을 꺼도 AI 작업에 필요한 이 통신은 발생합니다. Mosaic의 비밀번호 보관함 API는 AI 도구에 제공하지 않습니다.
- 업데이트 확인 버튼은 저장소가 설정된 경우에만 `api.github.com`으로 릴리스 목록을 조회합니다. URL과 앱 식별용 User-Agent를 보내며 페이지·대화·사용 횟수를 첨부하지 않습니다. 서버는 일반적인 네트워크 연결 정보(IP 등)를 볼 수 있습니다.
- 설치 안내, 릴리스 페이지, 문제 제보 또는 문의 링크를 직접 열면 기본 브라우저나 메일 앱이 실행됩니다. 공식 CLI와 Chrome의 자체 통신·업데이트는 각 제품에서 관리합니다.

## 진단 요약

**진단 요약 저장**은 사용자가 선택한 파일에 앱·런타임 버전, OS 종류와 아키텍처, 설정 복구·저장 오류 여부, 기록 동의와 위 숫자만 내보냅니다. 페이지 주소·내용, 대화, 개인 파일 경로, 계정·자격 증명은 넣지 않습니다. 자동 전송하지 않으며 공유 여부는 사용자가 결정합니다. 저장 후 내용을 확인하고 필요한 경우 직접 전달하세요.

이 기능은 개발용 원시 로그, 테스트 trace, 브라우저 프로필 백업과 다릅니다. 그런 파일에는 개인 정보가 들어갈 수 있으므로 대신 첨부하지 마세요. 제거 프로그램은 사용자 데이터 폴더를 지우지 않습니다. 영구 삭제가 필요하면 앱과 연결 Chrome을 종료하고 백업 필요 여부를 확인한 뒤 해당 폴더를 직접 관리하세요.
