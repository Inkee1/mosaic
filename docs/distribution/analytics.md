# 사용자 수 집계 연결

앱은 별도 동의 후 PostHog에 하루 한 번 `mosaic_active_day` 이벤트를 보냅니다. [Capture API](https://posthog.com/docs/api/capture), [수집 제어](https://posthog.com/docs/privacy/data-collection)를 참고하세요. 집계는 실제 사람 수가 아닌 **동의한 활성 설치 수**입니다.

## 연결

공식 0.7.5 베타는 소유자가 승인한 기존 PostHog 프로젝트를 Mosaic 집계에도 사용합니다. 수신 지역은 미국(US), 운영 표기는 **Inkee1 / Mosaic**, 문의는 tensordev9@gmail.com입니다. 인증된 운영자 대시보드는 `mosaic_active_day`만 집계하고 `test_run: true`는 제외합니다. 기존 제품의 이벤트는 Mosaic 지표에 합산하지 않습니다.

별도 검사 프로필에서 동의 전 전송 없음, 동의 후 실제 수신 1회, 같은 UTC 날짜 중복 전송 없음과 철회 후 전송 중지를 확인했습니다. 운영 집계는 이 검사 이벤트를 제외합니다. 기본 이벤트 보관 설정은 12개월이며 실제 정리 일정은 [개인정보 안내](privacy.md)에 기록합니다.

1. 소스로 자체 빌드하는 경우 소유자가 지정한 프로젝트의 수신 지역·접근 권한·서버 보관기간·문의처를 확정합니다. 다른 제품의 통계와 임의로 섞지 않습니다.
2. 루트의 `telemetry.config.json`에 `host`와 `projectToken` 두 필드만 지정합니다. 호스트는 해당 프로젝트의 `https://us.i.posthog.com` 또는 `https://eu.i.posthog.com`, 토큰은 공개 수집용 `phc_` 값입니다. 관리용 개인 API 키는 넣지 않습니다.
3. 이 설정 파일은 Git·소스 ZIP에서 제외됩니다. 패키징 도구는 검증된 설정만 설치 앱에 포함합니다. 설정이 없으면 집계 옵션이 비활성화됩니다. 소스로 빌드하는 사람은 자신의 프로젝트를 설정해야 합니다.
4. 빌드·패키징 후 공개 검사를 실행합니다. 요청된 집계 연결이 없거나 로컬 설정과 패키지의 수신 대상이 다르면 공개 검사에 실패합니다.
5. 별도 검사 프로필로 실제 수신을 확인합니다. 수동 검증 이벤트는 `test_run: true`를 붙이고 이용 통계에서 제외합니다. 자동 검사는 가짜 전송 함수를 사용하며 운영 서버로 전송하지 않습니다.

요금제의 현재 무료 한도와 초과 요금은 운영자가 확인하고 예산을 설정해야 합니다. 이 구현이 유료 가입이나 무제한 비용을 승인하지 않습니다. 실제 수신을 확인하기 전에는 연결 완료로 안내하지 않습니다.

## 지표 해석

일·주·월별 이벤트에서 `distinct_id` 고유 개수를 구합니다. UTC 기간, 버전과 동의한 설치만 포함한다는 조건을 함께 표시합니다. ID는 계정이나 기기 일련번호에서 만들지 않은 무작위 값이며, 재설치·동의 철회 후 재동의·별도 데이터 폴더에서 바뀔 수 있습니다. 비동의·오프라인 이용자는 누락되므로 전체 사용자 수로 주장하지 않습니다.

공개 수집 토큰으로 가짜 이벤트가 유입될 수 있어 이 수치만으로 감사된 실사용자 수를 보증할 수 없습니다. 다운로드 횟수, GitHub 별 수, 활성 설치 수를 구분해 보고하세요. AI 완료 횟수나 사이트 작업 성공률은 이 원격 집계 항목에 없습니다.
