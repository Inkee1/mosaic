# 공개 소개 문구

## 한국어

**여러 웹페이지와 AI를 한 화면에서.**

자료를 찾고, 콘텐츠를 비교하고, 여러 계정을 오가며 작업할 때 쓸 수 있는 Windows 브라우저 **Mosaic**를 만들었습니다.

웹페이지를 나란히 배치하고, 화면마다 로그인 계정을 나눌 수 있습니다. Claude Code 또는 Codex와 대화하면서 함께 볼 화면을 직접 선택하고, 필요하면 작업을 중지하거나 이어받을 수 있습니다.

한국어·영어를 지원하는 초기 베타입니다. 써 보시고 불편한 점과 개선 아이디어를 GitHub Issues에 남겨 주세요.

- [다운로드와 소스](https://github.com/Inkee1/mosaic)
- [설치 파일](https://github.com/Inkee1/mosaic/releases)
- [오류·개선 제안](https://github.com/Inkee1/mosaic/issues)

Windows x64용 미서명 베타라 실행 경고가 표시될 수 있습니다. AI 기능에는 본인 제공자 계정과 CLI가 필요합니다. 소스는 PolyForm Noncommercial 1.0.0 조건으로 공개하며 상업적 사용에는 별도 허락이 필요합니다. 사용자 수 집계는 선택 사항이고 기본적으로 꺼져 있습니다.

## English

**Your web pages and AI, side by side.**

I built **Mosaic**, a Windows browser workspace for research, content comparison, and working across multiple accounts.

Arrange pages side by side, keep separate accounts in each pane, and choose which pages Claude Code or Codex can work with. Stop the AI or take over whenever you need to.

This early beta supports English and Korean. Try it and share bugs or suggestions on [GitHub](https://github.com/Inkee1/mosaic). [Download the Windows beta](https://github.com/Inkee1/mosaic/releases).

Unsigned Windows x64 beta; Windows may show a warning. AI features require your own provider account and CLI. Source is available under PolyForm Noncommercial 1.0.0; commercial use needs separate permission. Usage counting is optional and off by default.
