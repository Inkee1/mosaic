# 개발과 기여 준비

Mosaic 자체 코드는 PolyForm Noncommercial 1.0.0 조건으로 공개합니다. 비상업 목적의 검토·수정·재배포가 가능하며 상업 목적의 수정·재사용에는 별도 허락이 필요합니다. [라이선스 안내](license-policy.md)와 원문을 먼저 읽으세요. 자신이 제공할 권한이 있는 코드만 기여하고 같은 조건으로 배포될 수 있음을 확인하세요. 별도 권리 양도나 상업적 재라이선스 권한이 기여만으로 자동 부여되지는 않습니다.

## 재현 환경

Windows x64, Node.js 24 계열과 npm을 사용합니다. 잠금 파일을 보존하고 아카이브를 푼 폴더에서 실행하세요. `npm ci`는 잠금 파일의 개발 도구와 Electron을 내려받으므로 인터넷 연결이 필요합니다. UI·네이티브 검사는 설치된 Google Chrome도 사용합니다.

```powershell
npm ci
npm run build
npm run test:core
npm run test:e2e
npm run test:desktop
```

테스트는 로컬 fixture와 임시 프로필을 사용합니다. 실제 AI 계정 로그인이나 유료 요청은 테스트 전제 조건이 아닙니다. 네이티브 검사는 Electron과 Chrome 실행이 허용되는 Windows 환경이 필요하며, 차단되는 환경에서 검사를 건너뛰고 통과했다고 기록하지 마세요.

개발 UI는 `npm run dev`, 데스크톱은 `npm run desktop`으로 실행할 수 있습니다. 웹 UI 미리보기는 실제 Electron 기능을 모두 실행하지 않습니다. 사용자 데이터와 분리하려면 데스크톱 실행 전에 전용 임시 폴더를 `MOSAIC_USER_DATA`에 지정하세요. 실제 프로필의 자격 증명이나 연결 파일을 테스트 fixture로 사용하지 마세요.

## 변경 검토

버그 수정에는 잘못된 동작을 재현하는 검사를 추가하세요. 권한 부여, 취소, 사람이 입력할 때의 중단, 프로필 분리, 외부 주소 검증과 안전한 종료 경계를 유지해야 합니다. AI 응답 완료와 웹사이트 작업 성공을 구별하세요. 저장·통신 동작이 바뀌면 [개인정보 문서](privacy.md)도 함께 갱신하세요.

UI 변경은 작은 창 크기, 키보드 조작, 모달 종료 후 웹 화면 복구를 확인하세요. 네이티브 동작 변경은 패키지 실행 파일에 `MOSAIC_TEST_EXECUTABLE`을 지정한 실제 Electron 검사로 확인하세요. CI는 Windows에서 빌드, 핵심·Chrome UI·패키지 네이티브 검사, 설치 검사와 배포 감사를 실행하도록 준비되어 있습니다. 이 저장소가 실제 원격 CI에서 실행됐다는 증거는 아닙니다.

## 소스와 의존성 관리

`.gitignore`는 보조 장치입니다. 공개 아카이브는 `node scripts/export-source.mjs`의 허용 목록과 감사를 통과한 바이트만 담습니다. `.env`, 사용자 프로필, 연결 파일, 암호화 저장소, 로그, trace, 캐시, 개발 기록과 심볼릭 링크는 포함하지 않습니다. 새 소스 경로나 확장자가 필요하면 허용 목록과 관련 검사를 함께 변경하세요.

테스트에는 예약된 `example.com`·`.test` 주소와 명백한 가짜 값을 사용하세요. 실제 토큰 모양의 검사 데이터가 필요하면 실행 중 조합해 만들고 실제 자격 증명을 사용하지 마세요. 테스트·문서라는 이유로 스캐너 검사를 통째로 끄지 마세요. 감사 출력은 규칙·상대 경로·줄 번호만 기록합니다.

의존성을 바꾸면 잠금 파일을 갱신하고 `npm audit`와 `npm audit --omit=dev` 결과의 영향을 구분해 검토하세요. 이 명령은 npm 레지스트리에 의존성 정보를 보내므로 실제로 실행할 환경에서 판단하세요. 실행물 고지와 개발 도구 범위는 [외부 구성요소 고지](third-party-notices.md)에 설명되어 있습니다.
