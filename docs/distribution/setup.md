# Mosaic 시작하기

Mosaic는 여러 웹 화면과 AI 채팅을 한 작업 공간에 모으는 Windows x64 데스크톱 앱입니다. 0.7.5는 비상업 이용 조건의 미서명 베타입니다. 공식 배포 경로는 [Inkee1/mosaic Releases](https://github.com/Inkee1/mosaic/releases)이며, 게시자 표기는 **Inkee1 / Mosaic**입니다.

## 설치와 실행

설치 파일 이름은 `Mosaic-0.7.5-win-x64-setup.exe`입니다. 한 번 실행하면 현재 Windows 사용자 계정의 기본 위치에 설치하며 관리자 권한을 요구하지 않습니다. 폴더를 고르는 마법사 없이 진행 상황만 표시합니다. 설치 전에 이전 Mosaic 창에서 사이트 작업을 저장하고 앱을 종료하세요. 설치가 끝나면 시작 메뉴의 Mosaic 바로가기로 직접 여세요. 바탕화면 바로가기는 만들지 않으며 설치 후 앱이 자동으로 실행되지 않습니다.

압축판은 `Mosaic-0.7.5-win-x64-portable.zip`입니다. 전체를 새 폴더에 풀고 `Mosaic.exe`를 실행하세요. 실행 파일만 다른 곳으로 옮기면 작동하지 않습니다. 압축판도 사용자 데이터는 Windows 사용자 계정의 앱 데이터 폴더에 저장합니다. USB 안에만 데이터가 머무르는 방식이 아닙니다.

다운로드한 파일의 SHA-256은 함께 제공된 `Mosaic-0.7.5-win-x64-SHA256SUMS.txt`와 비교할 수 있습니다.

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\Mosaic-0.7.5-win-x64-setup.exe
Get-AuthenticodeSignature -LiteralPath .\Mosaic-0.7.5-win-x64-setup.exe
```

이 베타의 설치 파일은 `NotSigned`가 정상입니다. 해시는 같은 파일인지 확인하는 수단이며 배포자의 신원을 보증하지 않습니다. 공식 저장소의 파일·해시를 확인한 뒤 실행 여부를 결정하세요. Windows가 경고를 표시하거나 조직 정책으로 실행을 차단할 수 있습니다. [문제 해결](troubleshooting.md)을 참고하세요.

## 첫 작업

1. **화면 추가**로 사용할 웹사이트를 여세요. 필요한 로그인과 인증은 해당 사이트에서 직접 완료하세요.
2. 프로필을 선택하세요. 같은 사이트라도 화면마다 별도 계정 상태를 유지할 수 있습니다. 기존 개인 Chrome 프로필을 자동으로 가져오지 않습니다.
3. AI를 사용할 경우 아래 공식 CLI를 준비하고 **Mosaic 설정 → AI 연결 다시 확인**을 누르세요.
4. 오른쪽 AI 채팅에서 새 채팅을 만들고 **함께 볼 화면**을 선택하세요. 처음에는 선택한 페이지 요약처럼 결과를 확인하기 쉬운 작업을 요청하세요.
5. 실행 중에는 **중지**를 사용할 수 있습니다. 중요한 변경, 제출, 결제 결과는 사이트에서 직접 확인하세요. AI 응답이 끝났다는 표시는 사이트 작업 성공을 증명하지 않습니다.

첫 실행 안내를 닫아도 사이드바의 **Mosaic 설정**에서 다시 확인할 수 있습니다. 사용 횟수 기록은 기본적으로 꺼져 있으며 켜지 않아도 앱을 사용할 수 있습니다.

## AI 연결 준비

Mosaic 설치 파일에는 AI 제공자의 CLI나 이용권이 포함되지 않습니다. 공식 CLI를 설치하고 자신의 계정으로 로그인하세요. 사용 가능 모델, 요금, 한도와 데이터 처리는 선택한 제공자 계정의 조건에 따릅니다.

| 제공자 | 공식 설치 안내 | 설치 후 터미널에서 로그인 |
| --- | --- | --- |
| Codex | [OpenAI Codex CLI](https://github.com/openai/codex#quickstart) | `codex login` |
| Claude Code | [Anthropic Claude Code 시작하기](https://code.claude.com/docs/en/quickstart) | `claude auth login` |

설치 후 새 터미널에서 `codex --version` 또는 `claude --version`이 동작하는지 확인하세요. Mosaic를 다시 열어 연결 상태를 확인하면 새 PATH 설정이 반영됩니다. 로그인 과정은 공식 CLI와 브라우저에서 직접 진행하며, Mosaic는 로그인 토큰을 복사하거나 전역 CLI 설정을 변경하지 않습니다.

일부 사이트는 내장 브라우저 로그인이나 표시를 제한합니다. 화면 제목줄의 **Chrome 연결**은 별도의 Chrome 창과 Mosaic 전용 저장소를 사용합니다. Chrome 설치가 필요하며 일반 Chrome 창의 계정과 자동 동기화되지 않습니다.

## 업데이트와 제거

**Mosaic 설정 → 업데이트 확인**을 눌렀을 때만 GitHub의 새 버전을 조회합니다. 배포 저장소가 미등록이면 안내만 표시됩니다. 새 버전이 있으면 릴리스 페이지를 열고 변경 사항과 서명을 확인한 뒤 직접 다운로드·설치하세요. 자동 다운로드나 자동 설치는 하지 않습니다.

설치판은 Windows의 설치된 앱 목록에서 제거할 수 있습니다. 제거 후에도 `%APPDATA%\MosaicBrowser`의 작업 공간, 계정 세션과 대화는 보존됩니다. 압축판 폴더 삭제만으로도 이 사용자 데이터가 지워지지는 않습니다. 데이터의 종류와 공유 시 주의점은 [개인정보와 저장](privacy.md)을 참고하세요.
