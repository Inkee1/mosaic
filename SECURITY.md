# Reporting a security issue / 보안 문제 제보

Please send security reports to **tensordev9@gmail.com**. Include the Mosaic version, Windows version, the affected feature, expected behavior and a minimal reproduction using a test account or local page.

보안 문제는 **tensordev9@gmail.com**으로 보내 주세요. Mosaic·Windows 버전, 문제가 발생하는 기능, 예상 동작과 테스트 계정 또는 로컬 페이지로 재현하는 절차를 적어 주세요.

Do not attach passwords, API keys, session cookies, real account data or the entire Mosaic profile. Public GitHub issues are suitable for ordinary bugs; report vulnerabilities privately so a fix can be prepared before details are published.

비밀번호·API 키·세션 쿠키·실제 계정 자료·Mosaic 사용자 데이터 폴더 전체를 첨부하지 마세요. 일반 오류는 GitHub Issues에 남길 수 있으며, 악용 가능한 취약점은 수정 전에 공개되지 않도록 이메일로 제보해 주세요.

Security fixes target the latest release. Response and resolution times depend on the maintainer's availability; no service-level guarantee is offered.
