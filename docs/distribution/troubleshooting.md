# 문제 해결

## Windows에서 실행을 막는 경우

현재 베타는 미서명입니다. 공식 [Inkee1/mosaic Releases](https://github.com/Inkee1/mosaic/releases)에서 받은 파일인지와 SHA-256을 확인하세요. 일반 SmartScreen의 **Windows의 PC 보호** 경고에서 실행을 선택하려면 **추가 정보 → 실행**을 누를 수 있습니다. 영어 Windows에서는 **More info → Run anyway**입니다. [Microsoft 배포 안내](https://learn.microsoft.com/windows/apps/package-and-deploy/publish-first-app)

실행 버튼이 없거나 Smart App Control·조직 정책이 차단하는 경우에는 IT 관리자에게 확인하세요. Defender가 악성코드를 탐지한 경우에도 위 일반 평판 경고로 간주하지 마세요. 앱 사용을 위해 보호 기능 전체를 끌 필요는 없습니다. Mosaic 도구는 Defender, Smart App Control, 실행 정책 또는 시스템 레지스트리의 보호 설정을 변경하지 않습니다.

설치 파일의 속성에서 디지털 서명을 확인하거나 다음 명령으로 상태를 읽을 수 있습니다.

```powershell
Get-AuthenticodeSignature -LiteralPath .\Mosaic-0.7.5-win-x64-setup.exe
```

`NotSigned`이면 서명되지 않은 파일입니다. `Valid`와 배포자 이름을 함께 확인하세요. 신뢰·조직 정책·평판에 따라 서명된 파일도 실행이 제한될 수 있습니다. 배포자와 코드 서명 준비가 끝나지 않은 상태를 앱에서 우회하지 않습니다.

## AI가 연결되지 않는 경우

공식 CLI가 설치되어 있는지 새 터미널에서 `codex --version` 또는 `claude --version`으로 확인하세요. 해당 CLI의 로그인 명령을 직접 실행한 뒤 Mosaic를 다시 시작하고 **Mosaic 설정 → AI 연결 다시 확인**을 누르세요. 모델 목록과 요금·한도 오류는 제공자 계정의 상태를 확인하세요. 공식 안내는 [시작하기](setup.md)에 있습니다.

AI가 화면을 찾지 못하면 채팅의 **함께 볼 화면**을 확인하세요. 닫힌 화면, 허용하지 않은 화면, 프로필이 바뀐 화면에는 다시 접근 허용이 필요할 수 있습니다. 사람이 페이지를 조작하거나 화면이 바뀌면 AI가 새로 관찰해야 합니다. 멈춘 작업은 상황을 확인한 뒤 재개하거나 새 요청으로 시작하세요.

## 사이트 로그인·흰 화면·새 창

사이트가 내장 브라우저를 제한하면 제목줄의 **Chrome 연결**을 사용하세요. 설치된 Chrome과 Mosaic 전용 별도 프로필이 필요합니다. 개인 Chrome의 기존 로그인 상태가 자동으로 넘어오지 않습니다. 준비한 로그인 세션도 사이트별 인증 방식에 따라 다시 로그인이 필요할 수 있습니다. 로그인과 인증 코드는 직접 입력하세요.

새 창의 실제 사이트 주소와 오류 안내를 확인하세요. 네트워크가 복구되면 F5 또는 Ctrl+R로 다시 시도할 수 있습니다. 실제 계정의 모든 OAuth·2단계 인증·사이트 호환성이 보장된 것은 아닙니다.

## 설정·대화 복구 메시지

설정 파일을 읽지 못하면 처음 사용 상태로 복구하며 사용 횟수 기록은 꺼집니다. 저장 오류가 계속되면 디스크 공간, 폴더 권한과 보안 프로그램 차단 여부를 확인하세요. 대화·작업 공간 파일 복구 문제는 앱을 종료하고 원본과 `.bak` 사본을 보존한 상태에서 조사하세요. 문제 해결을 위해 프로필 전체를 무작정 삭제하지 마세요.

## 업데이트 또는 설치 실패

저장소 미등록 안내는 현재 빌드에 공개 업데이트 주소가 아직 없다는 뜻입니다. 등록된 빌드에서 확인이 실패하면 네트워크 상태를 확인한 뒤 다시 시도하세요. 실패해도 현재 작업은 계속 사용할 수 있습니다. 자동 업데이트 설치는 지원하지 않습니다.

설치 파일을 실행하기 전에 사이트 작업을 저장하고 모든 Mosaic 창을 종료하세요. 새 버전을 기존 설치 위치에 설치하면 앱 파일을 갱신하고 사용자 데이터는 유지합니다. 이전 압축판 0.6.2는 별도 보관할 수 있지만, 같은 데이터 폴더를 공유하므로 동시에 실행하지 마세요. 이전 버전으로의 데이터 호환성은 별도 확인이 필요합니다.

문제를 전달할 때 앱 버전, Windows 버전, 재현 순서, 기대 결과와 실제 결과를 적어 주세요. 설정의 **진단 요약 저장** 결과를 먼저 검토한 뒤 필요한 경우 첨부하세요. 비밀번호, 인증 코드, 토큰, 실제 계정 화면, 전체 프로필 또는 원시 trace는 보내지 마세요. 공개 제보·문의 버튼은 승인된 저장소와 연락처가 설정된 빌드에만 표시됩니다.
